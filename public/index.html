📡 API Endpoints

Быстрый старт:

Сервер работает и готов к использованию. Используйте API для интеграции с вашим приложением.

Аутентификация

POST/api/auth/login - Вход в систему
GET/api/auth/me - Получить текущий профиль
POST/api/auth/change-password - Сменить пароль

Технологические карты (ТТК)

GET/api/ttk - Список всех карт (с пагинацией)
GET/api/ttk/:id - Получить карту по ID
POST/api/ttk - Создать новую карту
PUT/api/ttk/:id - Обновить карту
DELETE/api/ttk/:id - Удалить карту
POST/api/ttk/import/json - Массовый импорт JSON

Экспорт

GET/api/export/ttk/:id/pdf - Скачать PDF
GET/api/export/ttk/:id/excel - Скачать Excel
GET/api/export/ttk/:id/json - Скачать JSON
GET/api/export/all/excel - Все карты в Excel

Ингредиенты

GET/api/ingredients - Список ингредиентов
GET/api/ingredients/search/live?q=... - Живой поиск
POST/api/ingredients - Добавить ингредиент

Пользователи (Admin only)

GET/api/auth/users - Список пользователей
POST/api/auth/users - Создать пользователя
PUT/api/auth/users/:id - Обновить пользователя
DELETE/api/auth/users/:id - Удалить пользователя

Статистика

GET/api/stats/dashboard - Дашборд статистики
GET/api/stats/activity - Лог активности

Прочее

GET/api/qrcode - QR код для подключения
GET/api/health - Проверка здоровья сервера

🔧 Примеры использования API

// 1. Войти в систему
const loginResponse = await fetch('/api/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ username: 'admin', password: '0000' })
});
const { token, user } = await loginResponse.json();

// 2. Получить список ТТК
const cardsResponse = await fetch('/api/ttk?limit=50', {
  headers: { 'Authorization': `Bearer ${token}` }
});
const { cards, pagination } = await cardsResponse.json();

// 3. Создать новую ТТК
const newCard = {
  title: 'СОУС НОВЫЙ',
  yield: 100,
  type: 'sauce',
  tu: 'ТУ 10.84.12-001-2024',

  steps: 'Смешать ингредиенты...',
  org: 'Однородная масса...',
  haccp: 'ККТ-1 контроль...'
};

const createResponse = await fetch('/api/ttk', {
  method: 'POST',
  headers: { 
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${token}`
  },
  body: JSON.stringify(newCard)
});
