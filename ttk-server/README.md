# TTK Professional Server v2.0.0

Профессиональная система управления технологическими картами (ТТК), калькуляционными картами, рецептами для пищевого производства.

## 🚀 Возможности (57 функций)

### 🔐 Система доступа (3 уровня)
- **Гость** - просмотр без пароля
- **Оператор** - создание, редактирование, печать ТТК (пароль 0000)
- **Администратор** - полное управление, роли, доступы, сброс паролей

### 📊 Дашборд и Аналитика
- Статистика в реальном времени
- Графики по типам карт
- Динамика производства по месяцам
- Популярные карты
- Активность пользователей

### 📋 Управление ТТК картами
- Создание/редактирование/удаление карт
- Типы: блюда, соусы, салаты, супы, десерты, напитки, полуфабрикаты
- Ингредиенты с брутто/нетто расчётом
- Технологические процессы с шагами
- HACCP/KKT контрольные точки
- Органолептические показатели
- Оценка качества (10 параметров)
- Версионирование карт
- Статусы: черновик, на согласовании, одобрено, архив

### 🥕 База ингредиентов
- Неограниченное количество ингредиентов
- Категории, единицы измерения, плотность
- Аллергены, поставщики, цены
- Условия хранения, сроки годности
- ГОСТ стандарты, штрихкоды
- Живой поиск

### 🏭 Производство

- Партии, штуки, кг

## 🚀 Быстрый старт

### Установка
```bash
cd ttk-server
npm install
```

### Запуск
```bash
npm start
```

Сервер запустится на `http://localhost:3000`

### Доступ по сети
- Откройте `http://[ВАШ_IP]:3000` с любого устройства в сети WiFi
- Отсканируйте QR-код для быстрого подключения с телефона

## 📡 API Endpoints

### Аутентификация
- `POST /api/auth/login` - Вход
- `POST /api/auth/register` - Регистрация (admin)
- `POST /api/auth/change-password` - Смена пароля
- `GET /api/auth/profile` - Профиль
- `PUT /api/auth/profile` - Обновить профиль

### ТТК Карты
- `GET /api/cards` - Список карт
- `GET /api/cards/:id` - Карта подробно
- `POST /api/cards` - Создать карту
- `PUT /api/cards/:id` - Обновить карту
- `DELETE /api/cards/:id` - Удалить карту
- `POST /api/cards/:id/ingredients` - Добавить ингредиент
- `POST /api/cards/:id/steps` - Добавить шаг
- `POST /api/cards/:id/haccp` - Добавить HACCP
- `POST /api/cards/:id/quality` - Органолептика
- `POST /api/cards/:id/scores` - Оценка

### Ингредиенты
- `GET /api/ingredients` - Список
- `POST /api/ingredients` - Создать
- `PUT /api/ingredients/:id` - Обновить
- `DELETE /api/ingredients/:id` - Удалить

### Производство
- `POST /api/production-requests` - Создать запрос
- `GET /api/production-requests` - Список запросов
- `PUT /api/production-requests/:id/status` - Статус

### Экспорт
- `GET /api/export/pdf/:cardId` - PDF
- `GET /api/export/excel/:cardId` - Excel
- `GET /api/export/json/:cardId` - JSON

### Импорт
- `POST /api/import/json` - Из JSON
- `POST /api/import/excel` - Из Excel

### Администрирование
- `GET /api/users` - Пользователи
- `PUT /api/users/:id/role` - Роль
- `PUT /api/users/:id/active` - Активность
- `GET /api/settings` - Настройки
- `PUT /api/settings/:key` - Обновить настройки
- `GET /api/activity-logs` - Журнал

### Дашборд
- `GET /api/dashboard/stats` - Статистика

## 📱 Мобильное подключение

1. Откройте сервер с компьютера
2. Зайдите в настройки → QR-код
3. Отсканируйте телефоном
4. Приложение откроется автоматически

## 🔧 Конфигурация

Создайте файл `.env`:
```env
PORT=3000
HOST=0.0.0.0
JWT_SECRET=your-secret-key
NODE_ENV=production
TELEGRAM_BOT_TOKEN=your-bot-token
```

## 📊 Требования к серверу

- Node.js >= 18.0.0
- 512 MB RAM минимум
- 1 GB свободного места
- Доступ к сети WiFi

## 🛡️ Безопасность

- Смените пароль администратора после первого входа
- Используйте HTTPS в production
- Регулярно делайте бэкапы
- Ограничьте доступ к серверу
